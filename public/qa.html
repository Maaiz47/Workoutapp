IronLog QA Checklist

Work through each section on a real device at ironlogmv.vercel.app. For every step, mark it PASS, FAIL, or SKIP (not applicable), and leave notes for anything that looks wrong or needs attention.

When done, hit GENERATE REPORT and paste the output back to Claude for review.

01
Splash Screen
Hard-refresh the app (or clear site data) to see the full splash sequence from scratch.
1.1
Barbell animation
The barbell bar slides in from the centre, then the plates fly on from off-screen. Big inner plate should land first, smaller outer plate on top.
1.2
IRONLOG wordmark impact
Text drops in, shockwave rings fire outward from the centre, floor beam streaks beneath it.
1.3
Background & loading bar
The gym image should be visible but very dark behind everything. Shimmer loading bar shows at the bottom. No clutter or overlapping elements.
02
Authentication
Test both tabs on the landing page. Use a test account or create a new one.
2.1
Landing page — Athlete tab
Four athlete feature cards visible. Tagline and motivational phrase animate in. "No subscription. No ads." text visible below the input.
2.2
Landing page — Trainer tab
Four trainer feature cards visible. No dollar price shown anywhere. CTA says "Get in touch" or similar — not a specific price.
2.3
Login — existing user
Enter an existing username → password screen appears → login succeeds and lands on home.
2.4
Register — new user
Enter a new username → prompted to create account → fill email + password → account created → lands on onboarding.
2.5
Wrong password error
Enter correct username, wrong password → clear error message shown, no crash.
03
Home Screen
Logged in as an athlete. Check the hero section and day cards.
3.1
Hero image & text overlay
Gym/barbell image fills the hero area. "LIFT · TRACK · PROGRESS" and a motivational phrase overlay it at a readable size (they should feel prominent, not tiny).
3.2
Profile button overlay
Profile button sits inside the hero image (glass blur, no solid background behind it). Scrolling down fades it out.
3.3
Day cards layout
If plan has 4+ days → 2-column grid. Fewer than 4 days → single column. Each card shows the AI workout image.
3.4
Scroll parallax & 3D effects
Hero image moves slightly slower than scroll (parallax). Day cards animate in with a subtle 3D entrance effect.
3.5
Motivational phrase rotates
Wait ~6 seconds — the phrase should crossfade to a new one. Check it happens smoothly with no flash.
04
Workout Session
Tap a day card to start a session. Go through at least one exercise fully.
4.1
Start session
Tapping a day card opens the session view. Exercise list loads. Other day cards lock (greyed out).
4.2
Log a set
Enter weight and reps for a set and tap the log button. Set saves and shows in history below. Rest timer starts automatically.
4.3
Personal best detection
Log a weight heavier than any previous set for that exercise — a PB indicator should appear.
4.4
Add exercise from browser
Tap add exercise → browser opens → search for an exercise → tap to add it to the session.
4.5
Finish session
Complete session → summary screen shows sets logged, volume, duration. Session is saved and appears in history.
05
Custom Plan
Test plan generation and customisation from the home screen.
5.1
Generate plan via onboarding
If no plan yet — onboarding runs, asks about goals/equipment/days → plan generates and replaces the default split on home screen.
5.2
Customise a day
Tap CUSTOMISE → select a day → modify exercises → save. Changes persist on home screen.
5.3
Regenerate plan
Tap regenerate (if available) → new plan generates with different exercise selection. Old plan replaced.
06
Profile & Progress
Tap the profile button on the home hero to access profile/settings.
6.1
Profile opens
Tapping the profile button opens the full profile view with username, avatar, XP/streak stats, and tier badge.
6.2
Client tier badge
Tier badge shows the right animal emoji + tier name. Colour matches the tier (each tier has a distinct colour — Kitten=grey, Monkey=purple, Fox=orange, Tiger=yellow, Lion=orange-gold, Gorilla=red).
6.3
View Progress
Progress section loads charts — strength trends, streaks, body metrics. No blank screens or errors.
6.4
Body metrics — log an entry
Add a body weight entry → it saves and appears in the chart. Check the graph updates.
6.5
Settings — HIIT preferences save
Change HIIT settings → tap SAVE HIIT SETTINGS → reload page → settings still show the saved values.
6.6
Trainer upgrade — no price shown
In Settings, the "BECOME A TRAINER" card should have no dollar amount. Should say something like "Get in touch" or "request upgrade" without a specific price.
07
Messages
Requires at least one conversation thread (trainer↔client relationship needed).
7.1
Inbox loads
Messages section opens and shows conversation list. No infinite spinner.
7.2
Send a message
Open a thread → type a message → send. Message appears in the thread immediately with a sent indicator.
7.3
Read receipts
When the other party reads a message, the receipt indicator updates (sent → delivered → read).
08
Trainer Features
Log in as a trainer account for this section.
8.1
Trainer badge
Profile shows trainer tier badge in format: 🎯 COACH · TRAINER (tier name first, then TRAINER). Colour matches the tier.
8.2
Search for a client
Use the search bar on home → type a username → results appear → tap to view their profile.
8.3
Client roster loads
Client list shows all adopted clients with their names, tier badge, last session, and streak.
8.4
View client detail
Tap a client → their session history loads, stats visible, full workout log accessible.
8.5
Build & propose a plan
In client detail → Edit Plan → generate or customise → Propose to Client. Client sees it as a proposal in their inbox.
8.6
Client leaderboard
Client Leaderboard section loads and ranks clients by intensity points. Tap expand to see the ranking.
09
Leaderboard Groups
Create and manage a cross-trainer leaderboard group.
9.1
Create a new group
Tap + NEW GROUP → enter name → choose public/private → create. New group appears in the list immediately.
9.2
Add a client to the group
Expand a group → tap a client row under CLIENTS IN GROUP — it should toggle the checkmark and the change should persist (client added/removed from group).
9.3
Include me in ranking toggle
Toggle "Include me in ranking" → state saves. Reopen the group panel — toggle reflects saved state.
9.4
Invite another trainer
Search for a trainer username → FIND → result appears → tap INVITE. The trainer shows as "INVITED".
9.5
Delete group
Tap DELETE GROUP → confirm prompt → group disappears from list. Only group creator should see this button.
10
Notifications & PWA
Best tested on mobile (add to home screen first on iOS).
10.1
Push notification enable
In Settings → Notifications → tap ENABLE → browser prompts for permission → grant it → status changes to ✓ ENABLED.
10.2
Test notification fires
Tap SEND TEST NOTIFICATION → a push notification arrives on device within a few seconds.
10.3
App installs to home screen
On iOS: Share → Add to Home Screen. On Android: browser install prompt. App opens full-screen with no browser UI.
